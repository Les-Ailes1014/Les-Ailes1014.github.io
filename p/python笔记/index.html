标识符

在python程序中用来起名字的字符序列，如：变量名、类名、模块名等。

标识符命名规则：

1.由大写字母、小写字母、数字、下划线、汉字组成

2.对大小写敏感，不能以数字开头；

3.中间不能出现空格，长度没有限制。

从编程角度看：见名知意即可！

变量与常量

变量：Python编程中用来存储数据的最小单元，它有类型、名字、值

常量：类似数学中的常数，通常情况下，变量的值就是常量。

例：

a = 10

name = “张三”

pi = 3.14

基本数据类型

数值类型

整数类型

进制种类 引导符号 描述
十进制 无 默认情况，例：1100，-1100
二进制 0b或0B 由字符0和1组成，例：0b1010，0B1010
八进制 0o或0O 由字符0和7组成，例：0o1010，0O1010
十六进制 0x或0X 由字符09、af或A~F组成，例：0x1010，0X1010

任何进制数据转换成十进制-按权展开式

二进制->十进制 1010 = 1*2^3 + 0*2^2 + 1*2^1 + 0*2^0 = 8+0+2+0 = 10

八进制->十进制 167 = 1*8^2 + 6*8^1 + 7*8^0 = 64+48+7 = 119

十六进制->十进制 24B = 2*16^2 + 4*16^1 + 11*16^0 = 512+64+11 = 587 B = 11

复数类型

虚数部分通过后缀“J”

对于复数z，可以使用z.real和z.imag来表示它们的实数部分和虚数部分

运算符-关系运算符

运算符 举例 描述
< x < 1 判断 x 是否小于 y
> x > 1 判断 x 是否大于 y
<= x <= 1 判断 x 是否小于等于 y
>= x >= y 判断 x 是否大于等于 y
== x == y 判断 x 是否等于 y
!= x != y 判断 x 是否不等于 y

a = 5#将5赋值给a
print(a == 5)#判断变量a的值等于5吗？
print(a != 5)#判断变量a的值不等于5吗？
print(a >= 5)#判断变量a的值小于等于5吗？
print(a <= 5)#判断变量a的值大于等于5吗？

a = 5
b = 6
print(a>b and b==6) #有假则假，任意一边是false，结果就是false
print(a>b or b==6) #有假则假，任意一边是true，结果就是true
print(not (a>b)) #有假则假，任意一边是true，结果就是true

运算符-逻辑运算符

运算符 举例 描述
not（非） notx 如果 x 值为 True，结果为 False；如果 x 值为 False，结果为 True。
and（与） x and y x 或 y 任意一个为 False ， 结果为 False . 否则结果为True。
or（或） x or y x 或 y 任意一个为 True ， 结果为 True . 否则结果为False。
